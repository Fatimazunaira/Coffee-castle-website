# NUST Coffee Castle

## Run the client (website)

1. Install Node.js from nodejs.org
2. Open a terminal and run:
   git clone https://github.com/Fatimazunaira/Coffee-castle-website.git
3. Go into the client folder:
   cd Coffee-castle-website\client
4. Install packages (first time only):
   npm install
5. Start the website:
   npm run dev
6. Open the link it shows (usually http://localhost:5173/)

To get new changes later: run `git pull`, then `npm install`, then `npm run dev`.
